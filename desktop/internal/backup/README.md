# 流式备份存储

只保存发送端明确提交的归档，不参与手机资料增量合并。标准库、Go >=1.25。

- manifest 创建后不可改；同内容重试幂等，家庭/归档/文件 ID 只允许 ASCII 安全标识。路径由服务端生成，Label 只作公开显示。
- 单块最多8MiB，单文件64GiB、单归档1TiB/4096条；每文件最多65536块。断流、超长、摘要错都不确认偏移。已确认同块重试幂等；偏移冲突返回已确认位置。
- 原字节流式落盘，先块 SHA256、fsync 数据，再追加48字节二进制日志并 fsync。崩溃不完整日志和未确认尾部会截去。首次重启恢复重验前缀各块；正常同进程用文件尺寸/修改时间缓存避免每块重读整个前缀，最终仍重新读整文件验证 SHA。
- 最终全文摘要正确后发布 blob，再写验证 marker；未完成文件不提供下载。完整状态依据最近一次校验，不代替持续磁盘巡检。Check 会重新读取所有文件；损坏撤销 marker。
- 缺件保留原因；原照片/视频 source_exact=false 时即使摘要相符也不报完整。source_exact 是发送端经平台权限/独立源摘要验证后的声明，电脑不能凭收到字节证明 MediaStore 没有先脱敏或原视频未转码。
- 受限内容只能是一个不带标题/原文件名的 opaque sealed 容器，内部记录数/正文/缩略图/媒体清单应全部在客户端加密。电脑只验证密文字节，整体状态始终要求持钥者验证，不能把密文上传成功称为完整私密备份。浏览器 OpenVerified(...,false) 拒绝此容器；受控设备接口可下载密文。

目录由操作员选择，必须是可信私有目录，根目录自身拒绝符号链接，os.Root 限制路径逃逸；它不对抗具有同一 OS 账号权限、能篡改目录/运行进程的攻击者。不要将运行目录、数据库、令牌、TLS私钥或归档提交到 Git。

当前测试使用合成字节及临时真实文件，不等于 Android/iOS 原媒体授权、有效 HDR 编解码或真实手机备份已验收。
