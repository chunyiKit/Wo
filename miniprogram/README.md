## 首版范围与行为

- 首页沿用实际 Flutter 的日落摄影、酒棕/暖纸色板、衬线标题与圆角卡片；`design/` 不作为实现真相。成员与记录人优先显示真实上传头像，失败或未设置时 emoji 回退。真实头像经鉴权下载后作为本地文件展示。
- 支持微信登录、明确的新用户注册、原密码绑定、手机账号与微信账号恢复码找回、生成恢复码、退出当前/全部设备。恢复码仅在当页显示，不写本地存储、不复制到共享内容，离页即清。生成新恢复码会替换旧码。
- 支持记账月度汇总、预算内/外支出、分类、新增/编辑/删除与每月预算；时间转换为设备本地时区。金额按十进制字符串提交、以分汇总。
- 支持家务筛选、新增/编辑/删除、负责人头像、完成/撤销与重复家务标记。没有手动提醒按钮。创建或改派负责人、确认加入家庭会沿用现有后端的站内通知语义；本次测试全部使用合成账号，没有向真实成员发消息。
- 回忆首版为照片，最多 9 张，压缩后每张最多 10 MB，最长边 1920 且保留原比例；本机草稿按用户和家庭分区，图片持久保存。默认私密，正文 `client_id` 和附件 ID 固定，失败只在用户点击后继续；重试先确认服务端恢复私密，图片全部确认后才应用明确选择的家庭可见范围。
- 列表增删改后后台刷新，已有内容不换成整页 spinner；刷新失败保留已确认内容并提示重试。每个账号/家庭有独立 epoch，迟到响应不能回填新会话。会话过期保留按原用户分区的草稿，便于同账号重新登录恢复；明确退出时弹窗说明并清理该用户本机草稿、图片与媒体缓存。
- 回忆列表当前显示最近 50 条；首屏最多自动下载 8 张封面，其余图片点击才加载，私有媒体下载最多 4 并发。暂不支持视频、评论、完整历史分页、完整家聊迁移、支付、金融插件或系统推送。

## 私有媒体与资源

`privateMedia()` 仅接受相同 API origin 的相对路径，通过 `Authorization` 请求头下载。头像、家庭背景和回忆 raw 端点追加 `download=true`，服务端完成会员/作者权限校验后直接返回私有字节，避免带 Bearer 跟随跨域 COS 跳转。COS 对象保持 private，Bearer 从不放 URL。媒体临时文件在身份/家庭切换时清理。

原日落 PNG 约 2.06 MB，压缩为 `assets/sunset.jpg`（640×960，约 55 KB；实际值见体积检查）。原 25.1 MB Noto 字体不进包，默认使用设备系统衬线字体；`WoSerif` 为可选远程精简 WOFF2 字体，通过 `wx.loadFontFace(global:true)` 异步加载，失败保留系统字体、不阻塞首屏。若接入该选项，须自行提供有授权的字体子集及 HTTPS 静态域名，真机验证中文缺字、超时与字体加载成功；当前只验证调用与失败回退，未验证真实远程字体。

## 本地检查

需要 Node.js 22.18+（测试使用内置 TypeScript 类型剥离），TypeScript 编译器 6.0.3；运行时客户端零依赖。若已装 TypeScript，直接执行；没有时再通过可信 npm registry 安装 package.json 的开发依赖。

```sh
cd miniprogram
node --test tests/*.test.cjs
# 已有的 TypeScript 编译器或本地 node_modules/.bin/tsc：
tsc --noEmit
node tools/check-package.cjs
```

测试使用受控 wx 替身，覆盖金额、模板条件、登录离页、session 隔离、静默刷新、失败恢复与稳定 ID；不模拟真正微信身份。`types.d.ts` 是轻量宿主声明，基础类型检查不等同于完整微信 SDK 校验；本次另用微信官方 `api-typings` 核对原生 API 参数，后续开发应继续用官方类型/开发者工具校验。

只读视觉检查复用实际 WXML/WXSS 与合成数据：

```sh
node tools/visual-preview.cjs /tmp/wo-mini-visual
# 用浏览器打开 /tmp/wo-mini-visual/index.html?page=home&theme=cinema
# 支持 page=home/login/accounting/chores/memories，theme=cinema/paper。
```
